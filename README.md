### [Stride](https://github.com/Mahan-Imanian/Stride)

An algorithm lab that records every operation of a run and plays it back beside the queue, heap or call stack behind it. Two algorithms can run on the same input, so their counts compare directly.

<sub><a href="https://mahan-imanian.github.io/Stride/"><b>Live demo</b></a> · 18 algorithms, each tested against a reference implementation · React, TypeScript, Vite · MIT</sub>

### [Netcheck](https://github.com/Mahan-Imanian/netcheck)

Pings every Counter-Strike 2 server region before you queue, with jitter and packet loss for each, then traces the route to the fastest one. Usually enough to tell whether the lag is your Wi-Fi, your ISP or the link out of the country.

<sub><a href="https://github.com/Mahan-Imanian/netcheck/releases/latest"><b>Download</b></a> · Windows 11 · Rust, Tauri, React, TypeScript · MIT</sub>

### [Protonaut](https://github.com/Mahan-Imanian/protonaut)

Runs a Windows game build under GE-Proton in CI. If a change makes the game crash or render black, the pull request goes red with screenshots and logs attached, no Steam Deck required. Independent project, not affiliated with Valve.

### [QueueTTS](https://github.com/Mahan-Imanian/QueueTTS)

Save an article with a shortcut and it joins a queue to be read aloud, in order, using the voices already on the machine. Close the tab or restart the browser and it resumes at the sentence you left.

<sub>Chrome extension · no host permissions · plain JavaScript · end-to-end tested in Chrome</sub>
